# PCCheck 🖥️

**PCCheck** — это консольный инструмент на Python, который оценивает текущую конфигурацию вашего ПК для различных задач и помогает определить целесообразность и стоимость апгрейда.

## 🚀 Возможности

* **Оценка системы по задачам:** Расчёт производительности на основе CPU, GPU, RAM и типа накопителя в баллах от 0 до 10 для:
  * Программирования (Programming)
  * Игр (Gaming)
  * Монтажа видео (Video Editing)
* **Умный поиск комплектующих:** Поддержка подбора названий процессоров и видеокарт с устойчивостью к опечаткам и разным форматам записи.
* **Подбор лучших апгрейдов:** Анализ наиболее выигрышных вариантов модернизации с учётом цены, прироста производительности и фокусной задачи.
* **Итоговый вердикт:** Рекомендация о том, стоит ли делать апгрейд прямо сейчас[cite: 1].

---

## 🛠️ Установка и запуск

Не требует сторонних библиотек (использует встроенные модули Python)[cite: 1].

### Интерактивный режим

Просто запустите скрипт и ответьте на вопросы в консоли[cite: 1]:

```bash
python pccheck.py
Запуск с аргументами командной строки
Вы можете передать характеристики своего ПК через флаги[cite: 1]:

Bash


python pccheck.py --cpu "i5 12400F" --gpu "RTX 3060" --ram 16 --storage nvme
Доступные параметры:
--cpu: Модель процессора (например, i5 10400F, Ryzen 5 3600)[cite: 1].

--gpu: Модель видеокарты (например, GTX 1660 Super, RTX 3060)[cite: 1].

--ram: Объём оперативной памяти в ГБ (8, 16, 32 и т.д.)[cite: 1].

--storage: Тип основного накопителя (hdd, sata, nvme)[cite: 1].

--focus (опционально): Выбор приоритетной задачи (gaming, programming, video editing)[cite: 1].
